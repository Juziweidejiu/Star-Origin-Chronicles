星原战纪 · UI 改版总览

设计语言 / 组件规范 / 六屏改造 / 落地计划  ·  v1 待确认稿

「羊皮纸 + 墨线 + 黄铜」——把界面做成一本冒险者公会的手册。

01方向：从「后台管理系统」变成「公会手册」

当前界面最大的问题不是配色，而是所有东西长得一样重。

现状的诊断 深蓝底 + 灰边框 + 圆角矩形，卡片、按钮、导航、标签全是同一套皮肤；
正文大量 9–11px（全项目 11px 出现 121 次），层级靠「字更小更灰」堆出来；
三层导航（主导航 / 建筑栏 / 建筑内页签）选中态完全相同，用户不知道自己在第几层；
强调色散落使用青 / 黄 / 绿 / 紫 / 红，没有语义，S-D 印章的紫红橙黄绿又和资源色打架。
改版的三条原则
  1. 一屏一个主角：每页只允许一个酒红主按钮，其余全部降为次级。
  2. 纸与墨承担层级：用纸张底色深浅分「页面 / 卡片 / 浮层」，不再靠字号缩小。
  3. 颜色只表达含义：黄铜=可交互、酒红=主要行动、绿=安全、橙=危险、紫=秘法。等级印章改为单色描边，不再抢占语义色。
为什么是纸？ 这是酒馆、公会榜、手绘地图、赏金单的世界。纸面天然解释了「为什么这里有一张卡片」，也让 emoji 图标不再突兀——后续可逐步替换为线性图标。

04六个界面怎么改 SCREENS

每个界面回答一个问题，主按钮只有一个。

① 首页 · 一屏指挥 「现在该做什么？」

改前开局落在「据点」页，先看到一排建筑图标，要自己判断去哪。
改后首屏直接给一张「今日优先」大卡：D 级史莱姆、87% 势均力敌、理由、奖励，主按钮「接取并出发」。下面才是次要悬赏、队伍状态、城镇入口。

② 公会 · 悬赏板 + 决策抽屉 「今天打哪一张？」

改前任务卡纵向排开，胜率、战术、出战队伍分散在卡片内外，接哪张要靠自己算。
改后上半紧凑翻阅 S–D 全部在榜契约；底部常驻抽屉实时显示「出战 4 人 → 这张 68% → 建议这么打 → 特产是这些」，接取按钮就在抽屉里。

③ 名册 · 出征编队 「带谁去、扛不扛得住？」

改前英雄卡平铺，九维属性全部展开，看不出阵型与体能。
改后上方 3×3 站位（前排/中坚/后卫）+ 下方选中者详情：CA/PA 星级、压力士气、四组 30 维折叠。底部固定「换人 / 出发」。

④ 地牢 · 手绘路线图 「下一间走哪边？」

改前房间是竖排卡片列表，分支用文字描述，缺乏「在迷宫里」的感觉。
改后纸面手绘地图 + SVG 节点连线（战斗/事件/营地/宝箱/首领），已清打勾、当前高亮、未解锁虚线；点节点，下方面板给收益与预估胜率。

⑤ 战斗 · 隐形格战术战场 「这一仗怎么打？」

改前自走棋式 3×3 小棋盘，格子显性，单位和格子一样大，首领毫无压迫感。
改后一整间窟室：石砖后墙 + 壁炬 + 连续地面 + 散落武器；格线平时不可见，但 Boss 真实占 2×2、英雄各占 1 格，点击才闪格提示。底部是时序条 + 四张奥义卡。

⑥ 城镇设施（铁匠铺 / 市集 / 酒馆 / 医馆）

改前和公会任务卡同一套皮肤，信息密度高但层级平。
改后沿用卡片语言 + 顶部材料条；四个子页（打造/重铸/洗练/分解）改用黄铜描边 segmented，不再和主导航撞脸。本轮不做独立样张，直接跟随 token 落地。
① 首页样张 ② 公会样张 ③ 名册样张 ④ 地牢样张 ⑤ 战斗样张 全部原型画廊
