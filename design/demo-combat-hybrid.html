方案三 · 沙盘 + 巨型首领

保留方案一的下方 3×3 站位操作，把方案二的大尺寸独立首领与呼吸动效搬到上方舞台。

布局分工

  • 上层 262px — 首领巢穴：独立大造型、随行小怪、铭牌与三段血条
  • 下层棋盘 — 前排 / 中坚 / 后卫，保留拖拽换位与射程判定
  • 时序条 — 敌我出手顺序一览，Boss 也在队列中

呼吸动效

  • 周期 4.8s ease-in-out，缩放仅 1.028、上浮 3.5px
  • 呼吸挂在 .boss-stand 外层，内部造型槽随便换，动效不受影响
  • 受击只叠加 hitShake 短抖动，不打断呼吸节奏

给立绘 / 模型留的接口

  • [data-art] 三个状态：silhouette / portrait / model
  • 首领与两名小弟共用同一套造型槽开关，点右上角按钮三态同步切换
  • 首领立绘建议 560×800、小弟 160×200，均为透明底 <img>
  • 模型槽留了透视落地格与 <canvas> 位置，three.js 只管渲染，位移仍由外层 CSS 控制
当前 Boss 与小弟都还是程序化剪影占位，立绘资源做好后直接替换对应槽位即可，动效与布局无需改动。
