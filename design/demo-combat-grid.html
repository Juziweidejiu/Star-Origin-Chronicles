方案三 v2 · 隐形格战术战场

双方各自一块 3×3，中间一条交锋带。格子不显示，但真实存在：单位用 CSS Grid 的 grid-area 占格，只是格线透明。

占格规则

  • 普通单位 1×1（赤耳盾手、四位英雄）
  • 精英 2×1 / 1×2（体型 ×1.10）
  • 首领 2×2（枭熊王，第 2–3 行 × 第 2–3 列）
  • 巨兽首领 3×2（体型 ×1.5，向上溢出 30%）

为什么这次有层次

  • 同一坐标系：Boss 与我方站在同一套地面逻辑上，不再各演各的。
  • 接地阴影：每人脚下扁椭圆投影，贴在同一条地平线上。
  • 三排纵深：前排 1.0、中坚 .94、后卫 .87，同时压暗 3–10%。
  • 遮挡关系：前排单位压住后排下缘，遮挡即纵深。
  • 上边界溢出：Boss 身体越过自己格子向上生长，压迫感来自越界。

格子什么时候出现

  • 点任意单位 → 它占的格子淡金亮起 0.5 秒
  • 右上「网格」→ 临时显形/隐藏全盘格线
  • 拖拽换位时自动浮现，松手淡出（正式版）
  • AoE 覆盖格闪酒红 （点「集火首领」看效果）

造型槽接口

每个单位（含英雄）都有 剪影 / 立绘 / 模型 三态槽，右上按钮切换。出图按占格尺寸：

  • 首领 2×2 → 480×620
  • 英雄 1×1 → 200×260
  • 小怪 1×1 → 160×200
  • 巨兽 3×2 → 720×620

替换立绘时只需把这些尺寸的透明 PNG 填进 .art-portrait，占格与纵深逻辑完全不用改。
