> **本次修订重点**：

> 1. 彻底清除旧版残留的 **颜色词**（黑、青、白、红、赤、乌、金等）与 **温度/气候词**（寒、热、冰、霜、炎、烈）。
>
> 2. 彻底清除 **《迷宫饭》野炊/食材** 相关示例，全面对齐“**东方侠客奇幻 + 营地磨刀拭甲 + 打造材料掉落**”。

## 一、AI 味的五大病根（结构性禁令）

只列单个禁用词治标不治本，AI 会换个同义词继续套用固定模板。以下五种结构**一律封杀**：

1. **小说式空泛总标题**：如《星原战纪》《九川江湖志》《苍澜录》（“地域/天象 + 江湖/战纪 + 志/录/传”）。

2. **颜色与冷热修饰词滥用**：如“青石、黑窑、红土、白沙、乌铁、寒松、烈阳、冰霜、炎狱”。

3. **“A 与 B 的 C”翻译腔地名**：如“麦浪与风车镇”“翡翠泉与铃兰宿”。

4. **“高危姓氏 + 诗意双字”网文人名**：如“沈云舒”“墨微凉”“裴少陵”“楚清弦”。

5. **“形容词叠叠乐”怪物/任务名 + 中二二字词条**：如“暴食巨口泥沼长鳄王”“裂甲·穿云·断岳”“星陨砂”。

## 二、游戏总标题规范与备选（替代《九川江湖志》）

### 禁用规则

* 禁用 `XX志`、`XX纪`、`XX传`、`XX录`、`XX大陆`、`XX战纪` 等 AI 网文/页游后缀。

* 好名字应该像**一款真的在售的独立游戏或动漫**：短促、有动作感或器物感，不装腔。

### 六个去 AI 味标题备选

| 备选标题 | 气质定位 | 为什么不 AI | 
| ----- | ----- | ----- | 
| **《百炼行》** | 冒险 + 锻造双核心（最推荐） | 一眼点出“打铁百炼”和“游侠行旅”，利落不啰嗦 | 
| **《六合行会》** | 团队经营 + 公会悬赏 | 直接用游戏里的核心行会名，像正经策略 RPG | 
| **《游侠木牌》** | 市井江湖 + 接单跑团 | 木牌是行会接单的实体信物，有真实生活切口 | 
| **《开锋》** | 硬核兵器打造 + 战斗 | 两个字，纯铁匠与武侠手感 | 
| **《行客》** | 东方动画公路冒险感 | 干净克制，留白足，配二次元立绘很高级 | 
| **《三岔口》** | 传统江湖市井风 | 借用经典戏曲与真实路口意象，烟火气拉满 | 

## 三、人名规范（江湖市井风 + 动漫辨识度）

### 1. 禁用清单

* **高危姓氏**：沈、顾、陆、裴、墨、楚、季、洛、慕容、南宫。

* **高危字眼**：云舒、微凉、清弦、秋水、少陵、素问、破军、惊鸿、凌霄、无尘、夜、渊、寒、霜、炎、墨。

* **禁用西幻音译**：亚瑟、罗兰、艾莉娅、莱昂等。

### 2. 三套推荐命名公式

* **公式 A · 日常大姓 + 器物/节气/草木/单字（主力队员首选）**

  * 常用姓：陈、周、林、张、徐、唐、宋、石、许、方、吴、郑、胡、邓。

  * 常用名：砚、禾、铁、山、舟、桐、安、满、远、阿七、小满、半夏。

  * 示例：`周砚`、`林禾`、`石铁山`、`唐小满`、`许半夏`、`陈阿七`、`宋安`。

* **公式 B · 市井绰号 + 姓氏/排行（酒馆老兵、斥候、铁匠、向导）**

  * 示例：`独眼老冯`、`快手阿九`、`哑巴张`、`铁嘴王二`、`豁牙李`。

* **公式 C · 克制的正经名（仅用于极少数门派出身或官府角色）**

  * 示例：`韩伯仲`、`谢知行`、`赵承业`。

## 四、地名规范（零颜色、零冷热、真实地理逻辑）

### 1. 禁用清单

* 严禁所有 **颜色字**：黑、青、红、赤、朱、白、黄、金、银、蓝、绿、紫、翠、碧、苍、灰、墨、乌。

* 严禁所有 **温度/气候修饰词**：寒、热、冰、霜、炎、烈、暖（注意：“汤泉”指温泉，属固定地貌名词可用，不造“暖泉镇”“热汤谷”）。

* 严禁 **`A与B的C`**、**双字玄幻词**（霜月、星原）、**“深渊、幽暗、失落、远古、神殿”**。

### 2. 两套推荐命名公式

* **公式 A · 城镇聚落：`[地形/水文/建筑/物产] + [镇/渡/口/驿/堡/关/谷/湾]`**

  * 正面标准库：**石桥镇**、**铸剑谷**、**芦洲渡**、**汤泉镇**、**望山堡**。

* **公式 B · 野外与副本：`[近现代事由/地貌特征] + [具体场所]`**（严格线性历史，仅追溯至近三十年）

  * 正面标准库：**三岔口**、**塌方老矿**、**风口岭**、**百草涧**、**沉船湾**、**北松岭**、**西关旧垒**。

## 五、任务名规范（行会木板告示口吻）

### 1. 禁用结构

* 严禁 **`动词 + 形容词 + 怪物名`** 的 AI 说明文（如“清除暗河毒水巨蛙”）。

### 2. 三套推荐命名公式（紧扣材料掉落与江湖委托）

* **公式 A · 行会急件体（前缀 + 事由）**

  * `[急] 塌方老矿矿道清障`、`[官府] 征调：望山堡粮车护卫`、`[悬赏] 风口岭山贼截道`。

* **公式 B · 悬赏/收购体（直奔锻造材料与图谱）**

  * `收购：完整狼筋三十斤`、`求购：山牛角十对`、`收购：沉船湾桐油五桶`。

* **公式 C · 委托人求助体（带出江湖烟火气）**

  * `王掌柜的盐车陷在三岔口了`、`帮铸剑谷李师傅寻回失落图谱`、`替百草堂进涧采三株老药`。

## 六、怪物名规范（2\~5 字俗称化、零颜色、零冷热）

### 1. 禁用结构

* 严禁超过 5 个字、叠满形容词的 AI 拼装名。

* 严禁套用人类职业后缀（如“术师”“牧师”“驯兽师”）。

* 严禁带颜色或冷热字（如不要叫“白额头狼”“赤耳山魈”“冰霜巨猿”）。

### 2. 命名公式：`[1个外形/行为特征] + [常见俗称]`

* **肉盾型（靠部位/动作区分）**：`铁背山猪`、`厚壳泥龟`、`举盾山魈`、`发条木甲卫`。

* **输出型（靠体貌/攻击方式区分）**：`尖耳山魈`、`疾行水蜥`、`甩尾巨鳄`、`独眼头狼`、`展翼山雕`。

* **干扰/辅助型**：`毒斑巨蛙`、`鸣叫大蟾`、`井下胶妖`、`箱魅`。

* **区域头目（Boss）**：`断牙山猪王`、`独臂山贼头目`、`巨角山牛王`、`独眼巨汉`。

## 七、武器与《九阴真经》式打造词条规范

### 1. 禁用清单

* 严禁西幻/玄幻混搭词：`星陨砂`、`星辉指环`、`狼牙吊坠`、`奥术法杖`。

* 严禁二字中二词条：`裂甲`、`穿云`、`断岳`、`通脉`、`锋锐`、`窥机`。

* 严禁颜色与冷热字：`青霜剑`、`白蜡木`、`黑曜磨刀砂`、`乌铁`、`寒水淬刃`。

### 2. 四层武侠打造命名法

* **第一层 · 兵器形制（真实冷兵器，取代笼统的“长剑/短弓”）**

  * 剑刀类：`百炼直剑`、`八面汉剑`、`双股剑`、`雁翎刀`、`柳叶单刀`、`环首刀`、`斩马大刀`

  * 长兵/奇门：`齐眉硬木棍`、`点钢长枪`、`双刺`、`分水峨眉刺`、`判官笔`、`精钢护手`、`牛角反曲弓`

* **第二层 · 品阶与落款**

  * 凡铁制式（代打）：`熟铁雁翎刀`

  * 精工/宝兵：`百炼雁翎刀`

  * 手打神兵（自打高品阶）：`雁翎刀（林禾·铸）`

* **第三层 · 开光与批注（用铁匠工艺术语替代 AI 词条）**

  * 暴击率 → `血槽开锋` / `薄刃开尖`

  * 暴击伤害 → `重脊压锋` / `破甲棱`

  * 物攻加成 → `百炼锻实` / `熟铁包刃`

  * 穿透 → `三棱透甲` / `井水淬尖`

  * 攻速/手感 → `轻柄配重` / `合手缠绳`

  * 防具防御 → `双层夹铁` / `熟牛皮垫肩`

* **第四层 · 锻造材料（全部去色、去冷热、去玄幻）**

  * `生铁锭`、`精钢锭`、`老榆木`、`熟牛皮`、`水龟甲片`、`山牛角`、`精煤`、`桐油`、`砺石磨刀砂`。
