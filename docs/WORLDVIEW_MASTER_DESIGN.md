# 《百炼行》世界观、大地图与兵器系统总纲设计文档

> **文档定位**：可作为项目唯一世界观权威总纲放入 `docs/` 目录，用于统一前端文案替换、副本扩展及 AI 辅助生成约束。  
> **核心基调**：东方侠客奇幻风（人妖/异兽共存，行会、门派与官府并行，偏东亚动画质感）  
> **核心循环**：城镇接悬赏 → 野外清剿拿矿料与图谱残页 → 营地磨刀拭甲 → 回铸剑谷/铁铺百炼开光  
> **历史铁律**：严格线性历史，无超古代文明、失落科技或神迹降级，一切险地均源自近三十年现实变故。

## 第一部分：去 AI 味命名规范（v2 终版红线）

### 一、五大禁用结构（违反即重写）
1. **小说式空泛总标题**：禁用 `XX志`、`XX纪`、`XX传`、`XX录`、`XX大陆`、`XX战纪`（如《星原战纪》《九川江湖志》）。推荐正式标题：**《百炼行》**（备选：《六合行会》《游侠木牌》《开锋》《行客》《三岔口》）。
2. **颜色与冷热修饰词**：
   * 禁用所有 **颜色字**：黑、青、红、赤、朱、白、黄、金、银、蓝、绿、紫、翠、碧、苍、灰、墨、乌。
   * 禁用所有 **冷热气候词**：寒、热、冰、霜、炎、烈、暖（“汤泉”作地貌专名除外）。
3. **“A 与 B 的 C”翻译腔地名**：严禁“麦浪与风车镇”“翡翠泉与铃兰宿”。
4. **网文言情高危人名**：禁用姓氏 `沈/顾/陆/裴/墨/楚/季/洛`，禁用字眼 `云舒/微凉/清弦/秋水/少陵/素问/破军/惊鸿/无尘`，禁用西幻音译。
5. **叠词怪名与中二词条**：禁用超 5 字怪物拼装名（如“暴食巨口泥沼长鳄王”）、禁用人类职业后缀怪物名（如“哥布林牧师”）、禁用二字中二词条（`裂甲/穿云/断岳/星陨`）。

* **人名**：

* **怪物名（2~5 字俗称）**：
  * 盾位靠部位动作：`铁背山猪`、`厚壳泥龟`、`举盾山魈`、`发条木甲卫`

### 二、近三十年大事记与三方势力
* **三十年前**：前朝安平朝北伐失利裁撤北境边军，留下空关隘与发条木甲，**西关旧垒**与**北坡点将台**荒置。
* **二十年前**：西麓北坡暴雨塌方，官府封掉**塌方老矿**，矿工南迁至铸剑谷与矿场集。
* **十八年前**：石桥镇、铸剑谷与芦洲渡大商号合资立起民间**六合行会**，推行木板悬赏与游侠腰牌制。
* **八年前**：铸剑谷**天工匠门**改良水力锻锤与分段淬火法，百炼兵器与手铳传入民间。
* **近三年**：北境大雪封山、南境雨水偏多，山林异兽与水泽精怪外溢到官道边缘，行会悬赏激增。
* **并行势力**：**官府**（守城收税、外包清剿）、**六合行会**（发单担保）、**江湖门派**（天工匠门、芦洲漕帮、汤泉百草堂）。

## 第三部分：《九阴真经》式武侠武器与营地养护体系

### 一、兵器形制谱与五阶开光重数
* **兵器形制**：
  * 刀剑：`柳叶单刀`、`雁翎刀`、`环首刀`、`斩马大刀`、`百炼直剑`、`八面汉剑`、`双股剑`
  * 长兵/奇门：`齐眉硬木棍`、`点钢长枪`、`破阵大戟`、`双刺`、`分水峨眉刺`、`判官笔`、`精钢护手`
  * 远程/医乐：`牛角反曲弓`、`连珠弩`、`手铳`、`铁针匣`、`药杵杖`、`桐木琴`、`竹笛`
* **品阶与开光重数（对应 0~4 条词条）**：`凡铁（0）` → `精工（一重）` → `宝兵（二重）` → `名器（三重）` → `镇派神兵（四重圆满）`。

### 二、打造、落款、洗练与精淬规则
1. **老板代打 vs 自己动手**：老板代打耗 1.6 倍工钱、品质保底 `1.00~1.06`、无落款不涨熟练度；自己过三段锻造小游戏（鼓风火候 → 落锤锻打 → 井水/桐油淬火）最高可达 `1.18`，且 `≥ 1.10` 自动刻上**打造者落款**（如 `雁翎刀（林禾·铸）`）。
2. **开光批注池（替换原玄幻词条）**：
   * 暴击率：`血槽开锋` / `薄刃开尖`
   * 暴击伤害：`重脊压锋` / `破甲棱`
   * 物攻：`百炼锻实` / `熟铁包刃`
   * 穿透：`三棱透甲` / `井水淬尖`
   * 攻速：`轻柄配重` / `合手缠绳`
   * 防具/医乐：`双层夹铁` / `熟牛皮垫肩` / `定心雕纹` / `顺气木柄`
3. **定锋锁条与回炉精淬**：洗练时耗 **1 份`砺石磨刀砂`** 锁定 1 条开光批注；每件兵器限一次**回炉精淬**（全属性 `+18%`，前缀加 `精淬·`）。
4. **营地整备（替代原野炊）**：扎营三选一——**开锋磨刃**（耗磨刀砂，+暴击破甲）、**桐油拭甲**（耗桐油，+减伤防重伤恶化）、**校弦缠柄**（耗兽筋麻绳，+攻速命中并触发江湖夜话降压）。
