# 《百炼行》武侠武器形制与开光打造系统设计

> **设计目标**：将《九阴真经》的**兵器谱形制、开光批注、名匠落款、淬刃养护**融入现有铁匠铺（图纸 + 三段小游戏 + 洗练锁定 + 重铸），全面对齐《百炼行》世界观与 v2 去 AI 味命名规范。
>
> **工程对接**：可直接映射至现有的 `blueprintData.ts`、`craftEngine.ts`、`statResolver.ts` 与 `BlacksmithView.tsx`。

## 一、核心循环：从副本材料到传世名兵

```
【野外副本掉落】                【铸剑谷 / 铁匠铺】                【副本营地整备】
  矿石 / 兽筋 / 桐油 ──────▶ 1. 备料选图谱（制式代打 / 自己动手）     磨刀石：开锋磨刃
  门派图谱残页       ──────▶ 2. 三段锻造（鼓风 → 落锤 → 淬火）  ───▶ 桐油：拭甲防裂
  砺石磨刀砂         ──────▶ 3. 开光洗练（砺石砂锁定心仪批注）       毒囊：战前淬刃
                              4. 回炉精淬（每把兵器限一次 +18%）

```

## 二、兵器谱形制与品阶（告别笼统的“长剑/短弓”）

### 1. 江湖兵器形制库

不同形制对应不同职业定位与基础属性偏向，玩家在图纸册里能明显感受到“门派兵器库”的质感：

| 兵器类别 | 具体形制命名 | 适配职业定位 | 核心属性倾向 | 
| ----- | ----- | ----- | ----- | 
| **刀类** | `柳叶单刀`、`雁翎刀`、`环首刀`、`斩马大刀` | 剑圣 / 守望 | 高物攻、高破甲 | 
| **剑类** | `百炼直剑`、`八面汉剑`、`双股剑` | 剑圣 / 护卫 | 均衡物攻、高暴击率 | 
| **长兵** | `齐眉硬木棍`、`点钢长枪`、`破阵大戟` | 护卫 / 圣武 / 守望 | 格挡、护甲、前排压制 | 
| **奇门** | `双刺`、`分水峨眉刺`、`判官笔`、`精钢护手` | 剑圣 / 刺客系 | 高攻速、高穿透 | 
| **远程** | `牛角反曲弓`、`连珠弩`、`手铳` | 游侠 | 远距暴击、暴伤 | 
| **医乐器** | `铁针匣`、`药杵杖`、`桐木琴`、`竹笛` | 牧师 / 德鲁伊 / 乐师 | 治疗强度、法攻、韧性 | 

### 2. 五阶品阶与九阴式“开光重数”

保留现有 `T1 ~ T5` 品阶与装备稀有度，但在界面上用**江湖行话**呈现“开光重数”（对应词条数量 0\~4 条）：

* **凡铁（0 条开光）**：铁铺制式货，白板实用。

* **精工（1 条开光 · 一重）**：入门游侠标配，带 1 条工艺批注。

* **宝兵（2 条开光 · 二重）**：需中阶图谱与好炭好油，战力分水岭。

* **名器（3 条开光 · 三重）**：开始出现名匠落款，三项属性成型。

* **镇派神兵（4 条开光 · 四重圆满）**：全本图谱 + 顶阶玄铁 + 完美手打才能出世的毕业兵器。

## 三、打造双轨制：老板代打 vs 自己动手落款

直接复用现有的三段式锻造小游戏（**鼓风火候 5 次 → 落锤锻打 4 次 → 井水/桐油淬火 1 次**），强化两条路线的情感差异：

| 对比项 | 铁铺老板代打（制式兵） | 自己动手锻造（手打名兵） | 
| ----- | ----- | ----- | 
| **工钱与耗材** | 1.6 倍工钱，只耗基础矿木料（不耗精煤/桐油/磨砂） | 标准工钱（**铸剑谷减免 15%**），可自由加煤、桐油与砺石砂 | 
| **品质下限/上限** | 保底 `1.00 ~ 1.06`，稳定不翻车 | 视小游戏节奏判定，最高可达 `1.18` | 
| **匠艺熟练度** | 不涨熟练度 | 按品阶提升熟练度，满级后判定窗口更宽 | 
| **名匠落款** | 无落款（如 `熟铁雁翎刀`） | 品质 `≥ 1.10` 时自动刻上**打造者落款**，如 `雁翎刀（林禾·铸）` | 

## 四、开光批注池（替换现有 AI 词条，对接 `statResolver`）

彻底删掉“裂甲、穿云、断岳、通脉”等玄幻词条，改为**铁匠真实工艺批注**，底层依然严格映射至九维战斗面板：

| 对应九维属性 | 江湖开光批注名称 | 匠作含义 | 
| ----- | ----- | ----- | 
| `critChance`（暴击率） | **血槽开锋** / **薄刃开尖** | 刃口极薄，专寻甲缝要害 | 
| `critDamage`（暴击伤害） | **重脊压锋** / **破甲棱** | 刀背加厚配重，劈砍沉猛 | 
| `ad` / `ad%`（物攻） | **百炼锻实** / **熟铁包刃** | 反复折叠锻打，钢口扎实 | 
| `penetration`（穿透） | **三棱透甲** / **井水淬尖** | 刃尖硬度极高，专破重甲 | 
| `attackSpeed`（攻速） | **轻柄配重** / **合手缠绳** | 握持顺手，出招收招更快 | 
| `armor` / `magicResist` | **双层夹铁** / **熟牛皮垫肩** | 防具内衬加固，减免硬伤 | 
| `healingPower` / `ap` | **定心雕纹** / **顺气木柄** | 医者/乐师顺手器具，凝神聚气 | 

### 洗练与锁定规则（对接 M36 洗练锁）

* **重洗开光**：消耗铜钱 + 锻造石（或`粗铁砂`），重掷所有开光批注。

* **定锋锁条**：消耗 **1 份`砺石磨刀砂`**（替换旧“星陨砂”），可锁定 1 条心仪的开光批注（如先锁住 `三棱透甲 · 穿透 +12`），只重洗其余批注，逐步攒出四重满开光神兵。

## 五、回炉精淬（一次性强化上限）

保留现有 `reforged` 一次性强化机制，包装为**回炉精淬**：

* 每把兵器一生只能**精淬一次**（消耗精钢锭 + 铜钱）。

* 精淬后基础属性与所有开光批注统一提升 **+18%**，名称前加上 `精淬·`（如 `精淬·雁翎刀（林禾·铸）`）。
