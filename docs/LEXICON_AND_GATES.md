# 《三岔口》术语表与命名门禁

> 这份文档是**硬约束**，不是建议。任何涉及专名、装备名、怪物名、界面文案、叙事文本的改动，都必须先读这里，改完同步更新这里。

## 1. 五条命名铁律

1. **严格线性历史**：不存在远古高等文明、失落科技、上古神器、神殿降级设定。所有险地都必须能用近三十年的矿难、撤防、水患、兽群南迁解释。
2. **零颜色字、零冷热词**：专名与文案里不得出现 `青黑红赤朱白黄金银蓝绿紫翠碧苍灰墨乌` 与 `寒热冰霜炎烈暖`（「汤泉」作为地名例外）。
3. **禁翻译腔地名**：不得使用 `A与B的C` 结构（如「麦浪与风车镇」），城镇一律 `地形/水文/建筑/物产 + 镇/渡/口/驿/堡/关/谷/湾/集`。
4. **禁网文高危人名**：禁姓 `沈顾陆裴墨楚季洛` 与复姓 `慕容南宫`；禁字眼 `云舒/微凉/清弦/秋水/少陵/素问/破军/惊鸿/凌霄/无尘/夜/渊/寒/霜/炎/墨`；禁西幻音译。
5. **禁空泛与野炊**：禁 `深渊/幽暗/失落/远古/神殿/荒凉/废弃`；禁把史莱姆凝胶、五花肉、魔核一类野炊食材写进掉落与叙事；怪物名 2~5 字、禁人类职业后缀（术师/牧师/驯兽师）。

完整命名公式与示例见 [`NAMING_STYLE_GUIDE_V2.md`](./NAMING_STYLE_GUIDE_V2.md)。

## 2. 世界观总纲（一页版）

- 主轴：接悬赏 → 野外清剿拿矿料与图谱 → 营地磨刀拭甲 → 回城镇开炉打造、开光洗练。
- 五城：石桥镇（中州平川·六合行会总会）、铸剑谷（西麓矿山·天工匠门）、汤泉镇（西南药谷·百草堂）、芦洲渡（东南江海口·漕帮总舵）、望山堡（北境关山·远期开放）。
- 三方势力：官府、六合行会、江湖门派（天工匠门 / 漕帮 / 百草堂）。
- 时间线：三十年前北伐撤防 → 二十年前西山矿井塌方封井 → 十八年前六合行会立牌 → 八年前水力锻锤与分段淬火改良 → 近三年北境大雪、异兽外溢。
- 详见 [`WORLDVIEW_MASTER_DESIGN.md`](./WORLDVIEW_MASTER_DESIGN.md)、[`WORLD_MAP_V3.md`](./WORLD_MAP_V3.md)、[`WUXIA_WEAPON_AND_CRAFTING_SYSTEM.md`](./WUXIA_WEAPON_AND_CRAFTING_SYSTEM.md)。

## 4. 文案改动规约（每次都要做）

1. 改任何对外文案前，先跑 `npm run check`，确认当前门禁是绿的。
2. 改完必须同步：**本文件的术语表**（如有新词）、`PROJECT_HANDOFF.md` 的当次里程碑、`HANDOFF.md` 的里程碑表。
3. 新增叙事/AI 生成内容，先过 `validateNarrativeQuality(text, true)`；未通过不得入库。
4. 涉及数值（词条区间、图纸材料消耗、品质区间）的改动，不在文案 PR 里做；必须单独提交并附 `node scripts/sim_balance.mjs` 结果。

## 5. 命名门禁

门禁脚本：`scripts/check_naming.mjs`，由 `npm run check` 自动执行（`tsc -b && oxlint && node ../scripts/check_naming.mjs`）。

- 扫描范围：`mobile-pwa/src/**/*.{ts,tsx}` 中的**字符串字面量、模板字符串与 JSX 文本**（注释不参与，避免误伤设计说明）。
- 命中规则：颜色字 / 冷热词表（见 `src/types/narrative.ts` 的 `BANNED_COLOR_AND_TEMP_CHARS`）。
- **零豁免**：不设白名单。名字撞字就改名，不改规则。
- 例外仅一处：`validateNarrativeQuality` 内部的黑名单与字表本身（门禁脚本会跳过 `src/types/narrative.ts` 中的规则定义行）。

后续若要扩展检查（网文词、`A与B的C`、小说式书名），在 `scripts/naming_rules.mjs` 里加规则，并同步更新本节。
